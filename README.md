# Medicine Management App

A React Native (Expo SDK 57) mobile application designed to help users track and manage their daily medications efficiently, built with a focus on simplicity and accessibility.

## Tech Stack
- **Framework:** React Native / Expo
- **State & Database:** Local SQLite / Firebase integration
- **Build Tool:** EAS Build
